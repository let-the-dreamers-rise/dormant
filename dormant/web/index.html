Over 10,336 signable mainnet transactions. The conjunction never once occurred honestly, which is why it — not the nonce — is the alarm. The last row is the honest coverage figure: everything else returns unknown, never safe.

Nothing leaves this page. The decoder and the semantics library run in your browser; there is no server, no RPC call, and no telemetry. Paste an unsigned transaction — the base64 your wallet or squads.so shows you before you approve. Never paste a private key, here or anywhere.
Python library, tests and the measurement code: python -m dormant <base64>.
